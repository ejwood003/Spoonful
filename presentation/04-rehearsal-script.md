# Rehearsal script — 20 min + 3 Q&A

Run this **once with a timer** before presentation day. One person is timekeeper (not the current speaker).

## Hard rules

1. If speaking blocks run long, **cut lecture — never cut Task 1 below 5:00**.
2. Slide 16 stays up for the full live task; no new content mid-task.
3. Results slide: each person says **only their finding** (peer eval).

## Facilitator script (George) — Task 1

> “Same Task 1 from our user testing. Open the URL. My recipes → open a recipe → Make this recipe. Advance at least two steps. Timer starts now — five minutes. We’ll float if you’re stuck. No new slides until the timer ends.”

At 4:30: “One minute left — finish the step you’re on.”  
At 5:00: “Time. What did you notice about knowing which step you were on?” (max 30s)
