# Canvas submission checklist

**Key rule from rubric:** Prior to presenting, submit **all presentation materials** to Canvas.

This package is ready to turn into your deck and upload. Complete the paste slots, export, then submit.

## Upload package (before presentation day)

| # | Item | Status | Where |
| --- | --- | --- | --- |
| 1 | Final slide deck (PPTX / Google Slides PDF / PDF export) | Build from `03-slide-deck.md` | Canvas assignment |
| 2 | Live prototype URL (in deck + submission comment) | Paste into slide 1 & 16 | Canvas + slide |
| 3 | Speaker notes / run sheet (optional but useful) | `04-rehearsal-script.md` | Canvas or appendix |
| 4 | Supporting charts / persona cards / experience map | From your Drive/Canvas research | Embedded in deck |
| 5 | **Bonus (separate):** portfolio + LinkedIn case study links for **each** member | Not part of talk time | Canvas bonus field / comment |

## Pre-flight before you click Submit

- [ ] Every rubric must-have appears in the exported deck (see coverage below)
- [ ] Slide 16 Task 1 uses the **same wording** as user-testing Task 1
- [ ] Slide 15 has real feature-flag + WCAG content (Ethan / George)
- [ ] Slide 20 charts are the Survey Analytics visuals (not placeholders)
- [ ] Team names correct; product name **Spoonful** (repo may still say Kept)
- [ ] File opens offline (export PDF backup)
- [ ] Bonus links collected only if claiming +10

## Rubric coverage (must be visible in submitted deck)

- [ ] Anecdote + problem + alternatives + outcomes + discovery detail
- [ ] Root needs from qualitative data + 1–2 personas
- [ ] Experience map / flow / storyboard
- [ ] Core design → outcomes; IKEA effect; usability principle; design system
- [ ] Feature flagging; WCAG
- [ ] Task 1 card (room try — documented in materials)
- [ ] Test defense; set-the-stage de-bias; analyses; quant+qual; implications
- [ ] Iterations / limits / next steps; ethics

## How to submit (team action)

1. Build slides in Google Slides or PowerPoint from `03-slide-deck.md`.
2. Paste artifacts listed in `01-artifact-lock.md`.
3. Export **PDF** (and PPTX if required).
4. Upload to the Final Presentation Canvas assignment **before** your slot.
5. In the submission comment: live URL + (optional) link to this `presentation/` folder in GitHub.
6. If claiming bonus: paste four portfolio URLs (one per teammate).

## Portfolio bonus template (not presentation time)

Each member links a short case study: problem → research → prototype → testing → iteration. Pair with live MVP URL. Connect from LinkedIn Featured / About.
